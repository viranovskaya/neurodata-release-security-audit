# v0.2 calibration

This calibration checks whether the report remains understandable on data that were
not written specifically for the unit tests. It is not a privacy benchmark and does
not establish that any dataset is anonymous.

## Public datasets

The integrated scanner was run locally with the EEG and imaging readers installed.
All four runs completed with both integrity rechecks passing.

| Dataset | Entries | Files | References | High | Review | Info |
|---|---:|---:|---:|---:|---:|---:|
| BIDS `eeg_matchingpennies` | 85 | 54 | 21/21 valid | 0 | 2 | 7 |
| BIDS `eeg_rest_fmri` | 76 | 54 | 18/18 valid | 1 | 6 | 24 |
| BIDS Validator format fixtures | 669 | 519 | 14/16 valid | 1 | 70 | 143 |
| Four Sleep-EDF files | 4 | 4 | 0 | 0 | 12 | 0 |

The high finding in `eeg_rest_fmri` is a direct email in its README. The high
finding in the validator fixtures is a deliberately suspicious directory name.
These are expected release-review findings, not claims that the public sources are
unsafe.

The run also exposed a useful distinction: empty NIfTI fixtures and absent Git LFS
payloads must be reported as placeholders, not as broken format readers. That case
is now covered by a regression test.

## Real reader checks

A small NIfTI file created with nibabel 5.4.2 was scanned through the installed
reader. Header values were detected and masked; no voxel array was requested.

A small DICOM file created with pydicom 3.0.2 contained Pixel Data plus synthetic
patient, date, site, operator, device, email and UID values. The metadata was
detected and masked while `stop_before_pixels=True` kept the pixel payload outside
the reader.

These files are format exercises, not clinical data.

## Determinism and schema

The reviewer demonstration produced identical JSON and Markdown bytes on repeated
runs. The JSON matched `schema/report.schema.json`. Public-data reports matched the
same schema.

The controlled local wheel build is repeated as part of the final candidate gate.
Its hash belongs to the exact frozen commit and must not be reused after any source
change.
