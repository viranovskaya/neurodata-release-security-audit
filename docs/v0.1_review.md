# Local v0.1 review

Date: 22 July 2026

Version checked: `0.1.0.dev0`

This is an internal review of the private repository. It is not a public release or an independent validation.

## What is working

- The scanner reads one local directory without changing it.
- JSON, TSV, CSV, small text files, BrainVision metadata and EDF/BDF common headers are covered.
- EEG sample data are not loaded.
- Known names and old IDs can be supplied in a private file.
- Findings are masked in JSON, Markdown and report paths.
- Unsupported, unreadable and malformed files remain visible.
- Symlinks are reported and never followed.
- The scan does not open network connections.
- Repeated scans produce the same JSON.

## Decisions made during testing

Empty EDF/BDF fixtures and Git LFS pointers are reported as coverage notes rather than malformed recordings.

An alphanumeric EDF subject code is not labelled as a person name. It still produces a general review finding for the populated patient field. If the code is included in a private term list, it becomes a high-severity known-identifier finding.

Private-term matching uses word boundaries. A short name such as `Ann` does not match the word `annotations`. Different private identifiers receive different masked placeholders so report paths do not collapse into one entry.

Email addresses in filenames are detected and masked as well as emails inside files.
