# Security and sensitive-data reports

## Software vulnerabilities

Use **Report a vulnerability** under this repository's **Security** tab. Please
describe the affected version and provide a minimal synthetic reproduction.
If that option is unavailable, contact the maintainer through the email listed
on the GitHub profile with a short initial description and no sensitive values.

Do not include real participant data, an unredacted audit report, credentials or
a detected value. If a useful reproduction cannot be made safely, send only a
short description first.

## Findings in public datasets

This repository is not a disclosure channel for possible identifying metadata in
a third-party dataset. Contact the dataset owner or hosting repository privately.
Provide the dataset identifier, version, relative file path, field name and file
hash without posting the field value publicly.

## Scope

The audit helps find common privacy and metadata risks before release. A missed
finding, parser failure or unsafe report disclosure is relevant here. Whether a
dataset is anonymous, legally compliant or ethically shareable remains outside
the software's claim.
